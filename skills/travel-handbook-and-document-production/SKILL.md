# Travel handbook and document production

Keep itinerary facts, sources, and presentation layers separate.

## Workflow

1. Normalize dates, locations, transport, reservations, opening hours, and contingency notes.
2. Mark confirmed, estimated, user-provided, and unverified facts.
3. Generate maps, QR codes, tables, headings, and navigation from the structured source.
4. Render DOCX and PDF outputs using a repeatable command with a fixed output directory.
5. Inspect every page for overflow, clipped text, broken images, unreadable tables, and missing links.
6. Run text extraction or accessibility checks and compare counts with the source plan.
7. Publish the version, sources, generation timestamp, and known changes.

## Output

Produce a source plan, generated document, rendered preview, QA record, and versioned change note.
