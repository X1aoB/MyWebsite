# Resume and application tailoring

Every strong sentence should point to evidence.

## Workflow

1. Parse the target role into responsibilities, required skills, preferred skills, and signals of impact.
2. Build an evidence matrix mapping each requirement to a project, action, tool, result, and proof.
3. Mark facts as verified, approximate, inferred, or missing. Never fill a gap with a plausible number.
4. Rewrite bullets with action, scope, technical method, measurable result, and constraint where evidence supports it.
5. Keep terminology consistent across resume, project summary, portfolio, and interview explanation.
6. Check chronology, length, bilingual meaning, formatting, links, and confidential information.
7. Return open questions and a short rehearsal list for claims that need verbal support.

## Output

Produce a requirement-evidence matrix, tailored draft, fact-check table, formatting checklist, and unresolved questions.
