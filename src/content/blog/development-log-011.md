秋招刷力扣和 SQL 刷得头痛。最近小吉终端临近正式宣传上线，一直在给它做测试，后续还得录视频做宣传。Astra 确实好用，干活利索；问题是 Ultra 1.5x 一脚给额度蹬空了……下面是这几天的更新内容：

1. **项目正式更名为“小吉终端”，并推进到 1.0.0。** Project Snow 继续作为仓库和部署标识，公开网页、桌面入口、说明文档与图标统一换成“小吉终端”。新图标根据游戏截图做了高清修复，也补上了来源和处理记录；从 0.10 候选一路验收到 1.0.0 的过程中，旧域名、接口、IndexedDB 和已有聊天记录都保持兼容。

2. **把 22 名角色的立绘和表情全部接进舞台。** 这一轮共检查了 503 个表情与动作候选，其中 363 项重新修整、140 项确认无需修改；最终公开包包含 396 个基础表情状态和 60 个剧情动作，共 456 个呈现。素材经过逐像素合成核对、桌面与手机尺寸检查，文字通讯继续保持聊天界面，只有面对面场景才启用立绘、表情和剧情动作。

3. **继续磨日常聊天体验。** 表情会提前准备并尽量和对白同步，慢图最多只额外等待 240ms；切换时加入 160ms 的快速淡出淡入，并通过并行加载与解码缓存减少第一次见面时的等待。“接着昨天聊”被移到设置里，默认从今天开始，不再每次切角色都弹窗；文字聊天头像也放大到桌面 64px、手机 52px，同时重新调整了气泡、间距和窄屏布局。

4. **接入个人 Codex 订阅。** 现在可以在自己的电脑运行连接器，用配对码把网页和个人 Codex 登录连接起来，模型和推理强度会按账号实际支持的范围提供选择，包括 Astra、Sol、Terra、Luna 等，默认仍是 Luna Max。登录凭据留在本机，网页只保存当前标签页的短期配对状态；原来的 API Key 模式也继续保留。实际聊天、重新配对、限流、桌面和手机流程都做了回归测试。

5. **完成全角色 TTS 候选的内测材料。** 23 个主音色 / 变体、138 条试听和对应文件哈希已经完成归档与复核，也做了本机专用的语音测试入口。当前公网语音仍然关闭，不会让普通用户触发付费调用；后续如果继续推进，会坚持默认关闭、明确费用归属、限制每日额度，并优先解决音色权限与可靠扣费，而不是先把开关塞进线上。

6. **重新收紧正式发布与回滚链路。** 全面审查暴露了磁盘空间、保留期清理、共享数据库迁移、镜像门禁和浏览器恢复等问题，随后补上签名来源证明、主机容量检查、隔离基线恢复、限时人工候选验收、精确回滚和失败请求隔离。角色版本上线前还实际走过候选晋级、回退、再次晋级、桌面 / 窄屏浏览器验收与备份回读，不再把“CI 绿了”直接当成“线上肯定没问题”。

7. **开始做正式宣传前的最后准备。** 搜索元信息和站点地图已经换成小吉终端品牌；匿名统计被拆成独立、默认关闭的模块，只有明确同意后才记录去敏的完成事件，配置缺失时也不会影响聊天。宣传侧准备按产品介绍的形式制作 B 站视频，再整理一套百度贴吧图文；下一步先由我录制核心流程，再交给 Astra 剪辑和补字幕。

严格来说，1.0.0 的技术版本已经在线，但“正式宣传发布”还没有开始。现在主要是在反复测试配对、聊天、全角色表情、手机布局和回滚流程，尽量别等视频发出去以后才发现致命 Bug。等这一轮收口，就该硬着头皮录视频了。
