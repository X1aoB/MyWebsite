给Claude跪了，UI能力确实太强，最后优化一点就准备让他自己生成宣传视频了，终于可以让大伙都玩上了，确实爽。

下面是这几天的更新内容：

1. **整套界面升级成了“雪境 ADV”风格。** 面对面改为全屏视觉小说舞台，加入磨砂对白框、角色名牌、分层雪景、时间变化、白雪转场和地点标题卡；通讯器、设置、公告、弹窗与隐私页也统一了风格。电脑端新增终端开机演出，手机端则从锁屏和通知进入。

2. **继续整理对话理解、邀请和场景连续性。** 日常聊天、原作回忆和共同经历现在会分开处理，询问过去或假设地点不会误触发移动；自然语言与按钮共用地点识别，拒绝、延后、赴约、取消和跨日场景都补上了对应状态，断网恢复时也只查询原请求，避免重复调用模型。

3. **重做面对面交互与通讯器回复节奏。** 动作输入变成可收起的半透明浮窗，未完成邀约会显示在场景顶部；角色同意立即同行后会直接转场。每次真正进入面对面会触发一次到场问候，刷新或恢复不会重复生成；通讯器则先显示“正在输入”，再按更像真人聊天的节奏逐条送达完整气泡。

4. **补充界面色调和一批尘白风格细节。** 界面可以跟随舞台时间切换雪白、暮色和深色，远景加入晶体世界树、收容墙信标、基地编号与冰青色雪花。面对面舞台、弹窗、手机提示和网络错误也经历了多轮细节修正，角色立绘图层同时换成更轻的 WebP 资源，降低加载量。

5. **基地地图正式加入。** 现在可以在基地平面图里查看 22 位角色所在的房间和当前活动，区分实时位置、上次位置与暂无记录；桌面端地图和角色名单并排，手机端可以横向拖动。地图读取的都是本机状态，打开时不会调用模型。

6. **记忆、回看和长台词阅读继续完善。** 新增记忆档案，可以查看、筛选和删除角色记住的内容；台词可以收藏、搜索上下文并生成本地图片卡。面对面的长台词会自动分页，也支持手动翻页和自动阅读；22 位角色还补充了共 176 条日常活动。

7. **加入约定提醒和可选的主动消息。** 邀请角色时可以设置稍后或指定时间提醒，到点后能直接赴约或延后十分钟，这部分不调用模型。主动消息默认关闭，确认费用后才会启用，每个约定最多生成一条、每天最多三条，并且只在页面打开时工作，不会离线补发。

8. **模型设置和隐私说明同步更新。** API 凭证默认仍只保留在当前标签页，也可以主动选择在本机保存 2 小时、24 小时、3 天或 7 天；清除模型会话后会立即作废。设置新增“对话”分类，可调整文字速度、自动翻页、用量显示、约定提醒与主动消息，每轮回复也能查看本次模型调用和 token 用量。

9. **继续完善发布、回滚和宣传准备。** 沉浸式交互一轮使用 DeepSeek 完成 7 次受控测试，保守费用上限不到 0.08 元，CI、真实 PostgreSQL 与多尺寸界面检查均已覆盖。最新候选已经切到线上并通过服务器健康检查，旧候选继续保留作回滚；本机公网截图验收遇到 HTTP 403 后按规则停止，最后的收尾回执还在补齐。宣传片则会聚焦剧情问答、角色表情与动作、表情包、面对面互动和双端游玩，不把统计工程塞进主片。
